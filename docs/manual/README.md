# Manual do usuário (Quiver Tap)

O manual **canônico** para operação fica na aplicação:

**Configurações → Ajuda** (`/operacao/configuracoes/ajuda`)

- Artigos: `frontend/src/content/manual/*.md`
- Índice: `frontend/src/content/manual/manifest.ts`
- Prints: `frontend/public/manual/screenshots/`
- UI: `frontend/src/components/ManualWikiPanel.tsx`

Os arquivos `manual.html` e `Quiver-Tap-Manual-Usuario.pdf` nesta pasta são **legado** (fluxo por Eventos/Trailers) e não alimentam a aba Ajuda.
