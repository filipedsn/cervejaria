# Agenda e dashboard

## Agenda

Em **Agenda** o dono organiza quando e onde a operação está programada. Use para planejar dias de evento e evitar conflito de escala.

## Dashboard

O **Dashboard** reúne o resultado da operação: receita, formas de pagamento, produtos, turnos e comparativos do período.

![Dashboard](/manual/screenshots/11-dashboard.png)

1. Abra **Dashboard** (acesso de dono / permissão de leitura).
2. Escolha o período (mês ou intervalo, conforme a tela).
3. Use os blocos para entender o que vendeu e como receberam.

## Resumo de turno

Para um dia específico, o resumo do turno (após fechar o caixa) detalha aquele período operacional — complemento do dashboard mensal.

![Resumo do turno](/manual/screenshots/12-resumo-turno.png)

> Dica: o dashboard não substitui o fechamento de caixa. Feche o turno corretamente para os números baterem.
