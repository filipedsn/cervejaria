# O que é o Quiver Tap

O Quiver Tap é o sistema de operação do ponto de venda: registra comandas, preparo, caixa e acompanhamento do turno enquanto a equipe atende.

Ele foi pensado para trailer, quiosque e operações enxutas — poucos toques, celular ou tablet, sem burocracia no meio do serviço.

## Fluxo do dia

1. Configure o PDV (equipe, recursos, catálogo).
2. Abra o caixa para iniciar o turno.
3. Atenda pelas **Comandas** (ou venda avulsa).
4. Acompanhe a **Cozinha** / **Bar** se houver preparo.
5. Feche o caixa e revise o resumo do turno.

## Onde encontrar cada coisa

| Área | Para quê |
| --- | --- |
| Configurações | Equipe, PDV, aparência e este manual |
| Catálogo | Produtos, preços e cardápios |
| Caixa | Abrir e fechar o turno |
| Comandas | Atendimento do dia |
| Cozinha / Bar | Fila de preparo |
| Dashboard | Visão do dono após ou durante a operação |

> Dica: comece pelas seções **Configuração do PDV** e **Catálogo** antes do primeiro turno real.
